# Mémoire du coach course à pied

Ce dépôt (privé) est la mémoire durable de l'agent coach. Un fichier = une préoccupation ;
l'agent ne lit que les fichiers pertinents à la question posée, jamais l'ensemble du dépôt.

- `objectifs.md` — objectif courant, contraintes, préférences.
- `zones.md` — zones FC / allure EF actuelles, recalculées chaque semaine.
- `records.md` — meilleurs temps 2/5/10 km.
- `materiel.md` — préférences et notes matériel.
- `plan-semaine-courante.md` — le plan actif de la semaine.
- `journal/YYYY-Www.md` — un fichier par semaine ISO (ex. `journal/2026-W38.md`), créé par
  l'agent à la première interaction de chaque semaine. Contient les données Garmin de
  chaque séance et les points qualitatifs discutés (ressenti, gêne, nutrition, hydratation).
