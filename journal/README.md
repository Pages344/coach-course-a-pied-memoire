# Journal

Un fichier par semaine ISO : `YYYY-Www.md` (ex. `2026-W38.md`). Créé par l'agent à la
première interaction de la semaine concernée — jamais à l'avance, pour éviter des fichiers
vides qui polluent l'historique.

Structure attendue dans chaque fichier de semaine :

```markdown
# Semaine 2026-W38

## Séance du 2026-09-15 (mardi) — EF 45min
- Prévu : allure EF ~5:30/km, FC cible 130-140 bpm
- Réalisé (Garmin) : distance, allure moyenne, FC moyenne, dérive cardiaque
- Avant la séance : (résumé du check-in nutrition/hydratation s'il y a eu échange)
- Après la séance : (ressenti, gêne, chaleur perçue, rapportés par l'utilisateur)
```
